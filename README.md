### Принцип безопасного вывода данных

Для вывода текста из форм, `localStorage` или API используется `textContent`. Он вставляет строку как обычный текст. `innerHTML` разбирает строку как HTML, поэтому из непроверенных данных могут появиться элементы и обработчики событий.

## Практическая работа №17

Тема — DOM, события, поиск, фильтрация, сортировка и базовая валидация формы.

- `js/data.js` предоставляет каталогу массив `products` из шести моделей NOIR с готовыми фотографиями и описаниями. Демонстрация №16 использует отдельный учебный массив `practice16Products`.
- `js/catalog.js` создаёт карточки через `document.createElement()`, вставляет их через `append()` и обновляет каталог при поиске по названию, выборе категории и сортировке по цене или названию. Показываются число найденных товаров и сообщение для пустого результата.

В Chromium проверены каталог, галереи, ошибки формы и успешная проверка заявки. В Console использованы `console.log(catalogState)` и `console.table(products)`. Breakpoint в `updateCatalog()` показал, что запрос `aRCHIve 04` даёт один элемент в `preparedProducts` с идентификатором 4.

### Примечание к безопасности

Текст товаров и сообщений выводится через `textContent`. Пользовательские данные, данные из `localStorage` и будущего API следует выводить тем же способом.

## Практическая работа №18

В итоговом каталоге 10 моделей. Массив `products` формируется в `js/data.js`. У каждого товара есть уникальный числовой `id`, название `title`, категория механизма `category`, числовая цена `price`, признак наличия `isAvailable`, фото и описание. Для первых шести визуализаций подобраны названия реальных брендов по внешним признакам. Цены, категории механизма и наличие заданы для учебного каталога.

- Поиск проверяет вхождение запроса в название без учёта регистра и пробелов по краям. Фильтр сравнивает категорию товара со значением списка. Сортировка работает с копией массива и упорядочивает выборку по цене или названию.
- `input` запускает поиск сразу при вводе, `change` обновляет категорию и сортировку. Каталог пересоздаёт карточки через `createElement()` и `append()`, обновляет счётчик и показывает сообщение при пустой выборке.
- В каталоге и на странице товара у каждой модели три ракурса на прозрачном фоне. Галерея меняет изображение при нажатии кнопок, стрелок клавиатуры или горизонтальном жесте.
- Страница заявки проверяет имя, e-mail, телефон и остальные обязательные поля при `submit`. Ошибки видны рядом с полями. При успехе форма очищается, а на странице появляется подтверждение учебной проверки. `textContent` выводит названия, суммы и сообщения как текст.

### Самостоятельные доработки

- Кнопка «В корзину» работает на главной и в каталоге. Название карточки открывает страницу модели. Каждая модель занимает одну позицию. Интерфейс сообщает о добавлении, повторном выборе и удалении.
- Корзина хранит идентификаторы моделей в `localStorage` под ключом `noir-cart` и показывает фото, название, описание и цену каждой модели. Общая стоимость вычисляется функцией `calculateTotalPrice()` через `reduce()`.
- Счётчик и пустое состояние каталога, сброс заявки после валидации и пустое состояние корзины показывают результат действия на странице.

## Запуск

Открыть папку проекта в VS Code и запустить `index.html` через Live Server. Каталог, заявки и сохранение корзины проверяются по адресу локального HTTP-сервера. Для запуска достаточно содержимого репозитория.

### Текущее оформление

Палитра — чёрный, белый и серебро; шрифт Arial. Сохранён заголовок «Time makes perfect.», подпись «NOIR / Винтажные часы» и скруглённая кнопка «Открыть коллекцию» без стрелки. На широком экране высота hero — минимум 600 px. Нижняя часть фотографии плавно размывается и растворяется в цвете страницы через CSS-маски, градиенты и `backdrop-filter`.

Карточки товаров чёрные, с белым текстом и белой кнопкой заказа с чёрной надписью. PNG часов имеют прозрачный фон, падающие тени и тени карточек отключены. SVG-уголки белые; полупрозрачная область появляется при наведении и фокусе. На отдельной странице товара фон галереи совпадает с фоном описания. Преимущества представлены тремя простыми чёрными карточками с тонкой серебристо-белой рамкой и скруглениями 22 px. Слева — жирный заголовок и приглушённое пояснение, справа — стеклянная PNG-иконка часов, корзины или чата. Кнопок в блоках нет. На телефоне одна колонка, от 640 px — две, от 1024 px — три. Прозрачные изображения сохранены в `images/benefit-*.png`.

Иконки chevron-left/right взяты из [Lucide](https://github.com/lucide-icons/lucide), встроены локально; исходники и полный текст лицензии сохранены в `images/icons/`.
